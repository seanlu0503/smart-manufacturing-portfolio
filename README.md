# 智慧製造作品集入口頁

這是一個求職用的作品集入口頁，整合兩個以工廠生產製程與智慧製造為主題的前端作品：

- 工廠生產製程追蹤 Dashboard
- 工廠異常回報與維修派工系統

入口頁目標是讓面試官用一個網址快速理解我的求職方向、作品內容、技術棧與 AI 協作開發方式。

## 入口頁重點

- 製造現場流程路線：生產追蹤、異常回報、SLA 判斷、主管確認、維修派工、驗收結案、處理紀錄、改善追蹤
- 作品卡片：整理每個作品的使用情境、功能亮點、Demo 連結與 GitHub Repo
- 面試可講重點：針對每個作品列出能向面試官說明的核心能力
- 對應職缺方向：MES / 製造資訊系統助理、生管 / 製程改善助理、數位轉型 / AI 協作助理
- AI 協作流程：說明如何用 Gemini、Codex、Claude 協助需求拆解、前端實作與文案整理
